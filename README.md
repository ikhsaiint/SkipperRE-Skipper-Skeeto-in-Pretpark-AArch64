# SkipperRE-Skipper-Skeeto-in-Pretpark-AArch64
Native ARM64 PortMaster port of Skipper &amp; Skeeto in Pretpark (1997), powered by SkipperRE. Features SDL-based mouse controls, fullscreen gameplay, CD image support, and automatic game data extraction. Relive this classic point-and-click adventure on your retro handheld. Requires original game files.
